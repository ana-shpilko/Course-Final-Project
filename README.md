ОПИСАНИЕ ПРОЕКТА И ИНСТРУКЦИИ ДЛЯ ЗАПУСКА

Проект `task_planner` - это веб-сервер с функциями планировщика задач. Он подключается к базе данных, которая содержит детализацию следующих атрибутов для каждой задачи: дата выполнения, заголовок, описание, правило повторения при наличии. Реализована возможность подключения к внешнему файлу базы данных с помощью переменной окружения `TODO_DBFILE` (*).

Веб-сервер позволяет посмотреть весь список акутальных задач, добавить, изменить, удалить или отметить конкретную задачу как выполенную (в таком случае задача также удаляется из базы данных). Если задача выполнена или дата выполнения истекла, планировщик рассчитывает следующую дату для задач, подлежащих повторению. В качестве дополнительного функционала осуществлен алгоритм поиска задач(и) по дате и по ключевым словам (*). 

В проекте подготовлена база для создания docker-образа (*).

Номером порта по умолчания является 7540, но программа смотрит переменнную `TODO_PORT` на предмет указания другого порта в качестве рабочего и при необходимости использует ее значение (*).

Рабочие команды для создания docker-образа и последующего запуска контейнера: 
docker build --tag task-planner:v15 .
docker run -d -p 7540:7540 task-planner:v15

Адрес для открытия веб-сервера браузере: `http://localhost:7540/`.

Для запуска тестов рекомендуется использовать параметры по умолчанию.

Символами (*) обозначены упоминания заданий со звездочкой, которые были выполнены.
